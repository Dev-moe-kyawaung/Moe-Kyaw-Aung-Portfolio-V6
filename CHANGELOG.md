## [V6.0.0] — 2026-05-15 🚀

### ✨ Added
- Complete redesign with **Glasspunk / Transparent** aesthetic
- **Graphite & Copper** design system with CSS custom properties
- Custom cursor with smooth RAF animation
- Animated gradient hero (no external video dependency)
- Floating orb parallax background elements
- Gravatar profile integration (moekyawaung2026 & moekyawaung13721)
- GitHub real avatar from `avatars.githubusercontent.com`
- GitHub contribution chart via `ghchart.rshah.org`
- Animated stats counter (IntersectionObserver-triggered)
- Animated skill progress bars
- Testimonials auto-advancing carousel with dot indicators
- Image lightbox gallery with keyboard ESC support
- FAQ accordion with ARIA `aria-expanded` attributes
- Parallax scrolling bands between sections
- Dark / Light mode toggle with CSS `data-theme`
- Responsive hamburger mobile menu with animated bars
- Sticky bottom CTA bar with quick links
- Newsletter subscription form with email validation
- Mail collection section (4 addresses)
- Links collection masonry grid (9 links + Gravatar profiles)
- Organizations & Communities section (6 entries)
- Google Maps embed (Tachileik, Myanmar)
- Social media icon links (8 platforms)
- Back-to-top button with scroll threshold
- Preloader animation with fill bar
- WCAG accessibility — ARIA labels, roles, semantic HTML5
- SEO meta tags (OG, Twitter Card, description, keywords)
- Noto Sans Myanmar font for Myanmar language bio
- GitHub Actions CI/CD deploy workflow
- Complete project structure with modular CSS/JS files
- MIT License, CONTRIBUTING.md, .gitignore

### 🔄 Changed
- Migrated from simple HTML to fully modular project structure
- Replaced static gradient with animated keyframe hero background
- Upgraded from Font Awesome 5 to Font Awesome 6.5
- Switched body font from Inter → Outfit
- Switched display font → Syne (more distinctive)
- Mobile-first responsive redesign

### 🐛 Fixed
- Skill bars now animate only when section is in viewport
- Mobile menu closes on nav link click
- Form validation shows per-field errors with ARIA
- Carousel timer resets on manual prev/next click
