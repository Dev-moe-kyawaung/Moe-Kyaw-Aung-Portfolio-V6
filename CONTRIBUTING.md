# Contributing to Moe-Kyaw-Aung-Portfolio V6

Thank you for your interest in contributing! 🙏

## How to Contribute

1. **Fork** the repository
2. **Clone** your fork: `git clone https://github.com/YOUR_USERNAME/Dev-moe-kyawaung.github.io.git`
3. **Create a branch**: `git checkout -b feat/your-feature-name`
4. **Make changes** and commit: `git commit -m "feat: add awesome feature"`
5. **Push**: `git push origin feat/your-feature-name`
6. **Open a Pull Request** against `main`

## Commit Convention

Use [Conventional Commits](https://www.conventionalcommits.org/):

```
feat: add new section
fix: correct mobile menu overflow
style: update copper accent shade
docs: update README installation steps
refactor: extract skill bar to component
```

## Code Style

- Indent with **2 spaces**
- Use **CSS custom properties** (no hardcoded hex values)
- Add **ARIA labels** to all interactive elements
- Comment complex JS logic
- Keep JS vanilla (no frameworks)

## Reporting Issues

Open an [Issue](https://github.com/Dev-moe-kyawaung/Dev-moe-kyawaung.github.io/issues) with:
- Browser & OS version
- Steps to reproduce
- Expected vs actual behaviour
- Screenshot if applicable
