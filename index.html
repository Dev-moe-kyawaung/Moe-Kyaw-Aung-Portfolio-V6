About Me

Building Tomorrow's Mobile Experiences

I'm Moe Kyaw Aung, a Senior Android Developer based in Tachileik, Myanmar. With over 5 years of hands-on experience, I specialize in crafting scalable, production-grade Android applications using Kotlin, Jetpack Compose, and Clean Architecture.

My passion lies at the intersection of elegant code and exceptional user experience. I architect apps with MVVM/MVI patterns, implement offline-first strategies with Room and DataStore, and integrate Firebase for real-time backend capabilities.

Beyond Android, I bring Full Stack capabilities — from RESTful API design to CI/CD pipeline automation with GitHub Actions and Azure DevOps. I believe great software is built by teams that ship fast, iterate smartly, and measure everything.
